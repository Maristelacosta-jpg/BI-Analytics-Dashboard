# 📊 BI Analytics Dashboard

Dashboard interativo desenvolvido com Python, Streamlit, Pandas e SQL para análise de vendas e indicadores de desempenho.

## 🚀 Tecnologias Utilizadas

- Python
- Streamlit
- Pandas
- SQL
- Plotly
- Git/GitHub

## 📈 Funcionalidades

- Análise de faturamento
- Evolução de vendas
- Indicadores de performance
- Filtros interativos
- Visualizações dinâmicas
